# Ретест и регрессия после исправлений

Интерактивная версия: вкладка «Ретест» в [чек-листе тестировщика API](https://ikqavscode-afk.github.io/Sprint_5/checklist.html).

## Подготовка
- [ ] Получена сборка с исправлениями, зафиксирована версия API
- [ ] В окружении Postman заполнены `baseUrl` и `token`
- [ ] Выполнена папка «00 Подготовка»

## Ретест дефектов
- [ ] Запущены папки коллекции: «Наборы», «Доставка», «Корзина»
- [ ] Для каждого упавшего запроса проверены код и формат ответа
- [ ] Исправленные дефекты закрыты, неисправленные переоткрыты с комментарием

## Регрессия
- [ ] Позитивные сценарии: 1, 15 и 30 продуктов в набор, повторное добавление
- [ ] Доставка: время 07–21, обе ценовые категории
- [ ] Корзина: создать, добавить, получить, удалить
- [ ] Коды 404 и 405 для неверного URL и метода

## Новые проверки
- [ ] Закрыты серые зоны высокого риска (GZ1, GZ2, GZ5, GZ6)
- [ ] Добавлены проверки на новые границы значений
