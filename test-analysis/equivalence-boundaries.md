# Классы эквивалентности и граничные значения

## Параметры `POST /api/v1/kits/{id}/products` и `PUT /api/v1/orders/{id}`

| Параметр | Допустимо | Классы недопустимых значений | Граничные значения |
|---|---|---|---|
| `productsList` | непустой массив, до 30 позиций | отсутствует, пустой `[]`, не массив, 31 позиция | 0, 1, 30, 31 |
| `id` продукта | положительное целое до 2³¹−1 | `0`, отрицательное, `null`, строка, спецсимвол, > int, несуществующий | −1, 0, 1, 2147483647, 2147483648 |
| `quantity` | положительное целое до 2³¹−1 | `0`, отрицательное, `null`, строка, спецсимвол, > int, отсутствует | −1, 0, 1, 2147483647, 2147483648 |
| Заголовок `Content-Type` | `application/json` | отсутствует, неверный | — |
| Формат тела | JSON | XML вместо JSON, невалидный JSON | — |

## Параметры `POST /fast-delivery/v3.1.1/calculate-delivery.xml`

| Параметр | Допустимо | Классы недопустимых значений | Граничные значения |
|---|---|---|---|
| `deliveryTime` | час 07–21 | вне графика (06, 22), отрицательное, текст, спецсимвол, > int | 06, 07, 21, 22 |
| `productsCount` | 1–14 | `0`, отрицательное, `null`, текст, спецсимвол, очень большое | 0, 1, 7, 8, 14, 15 |
| `productsWeight` | 0,1–6 кг | `0`, отрицательное, `null`, текст, спецсимвол, очень большое | 0, 0,1, 2,5, 2,6, 6, 6,1 |
| Структура XML | корректная | незакрытый тег, нет обязательного элемента | — |
| Метод и путь | `POST`, верный URL | `GET`, неверный URL | — |

> Допустимость нулевых значений и разрывов между диапазонами — предмет [серых зон](gray-zones.md) GZ1 и GZ4.
